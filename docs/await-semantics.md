# PRD: AwaitSemantics (корневой)

label: await-semantics
topics: await, asynchronous, await context preservation, context preservation, await semantics, AwaitSemantics, template expression, interpolation, fragment interpolation

Кластер `svelte_analyze::await_semantics` — семантика уровня отдельного `await` внутри шаблонного выражения. Слой: `analyze.md`. Пер-выражение сосед — `ExpressionSemantics`.

## Назначение

Один вердикт на `await`-узел: что ещё исполняется в той же продолжающейся цепочке после того, как этот `await` разрешится. Ответ нужен обоим backend'ам, чтобы решить, оборачивать ли `await` в **сохранение контекста await**; сам выбор обёртки — их дело.

## Public API

`AwaitSemanticsStore::query(OxcNodeId) -> AwaitSemantics` — тотальный: id вне множества коллапсирует в `Detached`. Без `Option`.

Ключ — `OxcNodeId` самого `AwaitExpression`, не выражения: соседние `await` одного выражения получают разные варианты (`{await a() + await b()}` — первый `NonTerminal`, второй терминальный).

## Вердикт

- `NonTerminal` — после этого `await` вычисляется ещё часть того же выражения.
- `TerminalInFragmentInterpolation` — `await` разрешается последним, и его выражение есть интерполяция `{…}`, которую **фрагмент** рендерит сам.
- `TerminalInConstruct` — `await` разрешается последним, но выражение — часть объемлющей конструкции: разметки **элемента**, **атрибута**, заголовка **блока**, инициализатора **@-тега**.
- `Detached` — `await` не исполняется при вычислении шаблонного выражения (тело вложенной функции, скрипт).

## Архитектурные инварианты

1. **Позиция, не форма.** Вариант называет положение `await` относительно единицы шаблона, а не runtime-вызов. Подмена рантайма вердикт не меняет: клиентский backend оборачивает `NonTerminal`, серверный — `NonTerminal` и `TerminalInConstruct`, и это правило «вердикт → форма» живёт у них.
2. **Различие интерполяции и конструкции синтезируется из вида узла-владельца фрагмента**, а не из `FragmentRole`: у роли парсерная гранулярность (`<svelte:fragment>` делит `Element` с обычным элементом), которой для этого вопроса не хватает.
3. **Read-only после build.**

## Анти-паттерны

- Backend восстанавливает позицию сам — идёт вверх по AST от `await` или матчит вид узла-владельца («Анализ в кодгене»).
- Ответ собирается из blocker'ов и ссылок выражения вместо вердикта («Сырые факты»).
- Вариант несёт готовую `$.save`-обёртку («Эмит-форма семантики»).
